# SkillBridge

SkillBridge is a multi-platform workspace with web, desktop, mobile, and shared packages managed from one repository.

## Main workspaces

- `apps/web` - Next.js application for the primary product surface
- `apps/desktop` - Electron wrapper for desktop distribution
- `apps/mobile` - Expo application for iOS and Android builds
- `packages/shared` - shared Supabase and type utilities

## Common commands

- `npm install`
- `npm run lint`
- `npm run type-check`
- `npm run build`
- `npm test`
